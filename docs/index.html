A shoji is the sliding paper screen of a Japanese room: a thin frame that lets light through and keeps very little for itself. The browser works the same way. It uses the engine Windows already keeps up to date, and adds only what a browser needs.

  • About 12 MB engine not included, because Windows has it
  • No account no sync, no telemetry
  • No ads from the first launch
  • No bright websites dark mode, everywhere
  • No trace when you ask for it
